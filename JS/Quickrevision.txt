✅ What is a loop?
A structure that repeatedly executes code while a condition is true.

✅ Types of loops?
for, while, do-while, for-of, for-in.

✅ for vs while?
for → known iterations.
while → unknown iterations.

✅ while vs do-while?
do-while executes at least once.

✅ Infinite loop?
A loop that never terminates.

✅ Nested loop?
A loop inside another loop.

✅ Loop control statements?
break and continue.

✅ break vs continue?
break exits the loop.
continue skips the current iteration.

✅ When avoid loops?
When array methods (map, filter, reduce) provide a cleaner and more efficient solution.

Question	Short Answer
What is an array?	An ordered collection of elements stored in a single variable.
Why use arrays?	To store and manage multiple values efficiently.
How to create an array?	Using [], new Array(), Array.of(), or Array.from().
What is indexing?	The position of an element in an array, starting from 0.
Why index starts from 0?	Because the index represents the offset from the first memory location.
Array vs Object?	Arrays store ordered values using indexes; objects store key-value pairs.
Can arrays store different data types?	Yes, JavaScript arrays can contain mixed data types.
How to get length?	Use the .length property.
How to access elements?	Use array[index].
How to update an element?	Assign a new value using array[index] = value.
Access invalid index?	Returns undefined; no error is thrown for reading.
What is a sparse array?	An array with empty slots (holes) between indexes.
[] vs new Array()?	[] is preferred; new Array(n) creates an array with empty slots when passed a single number.
Empty array?	An array with no elements ([]), whose length is 0.




Which loop is fastest?	for
Which loop is most readable for values?	for...of
Which loop is best for side effects?	forEach()
Which loop returns a new array?	map()
Can forEach() use break?	❌ No
Which loop works well with async/await?	for and for...of
Which method is preferred in React?	map() because it returns an array of JSX elements.
When to use map()?	When transforming data into a new array.
When to use forEach()?	When performing actions like logging, updating state outside rendering, or accumulating values without needing a returned array.



Method	   Returns	    Original Array Modified?	Main Purpose

reduce()   Single value	❌ No	                  Aggregate values
some()	   Boolean   	❌ No	                  Check if at least one matches

map() → Transform data.
filter() → Select matching data.
reduce() → Convert an array into one value (sum, max, object, etc.).
some() → "Does any element match?"
every() → "Do all elements match?"
flat() → Remove nested array levels.
flatMap() → map() followed by flat(1).
sort() → Mutates the original array; use a comparator for numbers.
Comparator Rule → Negative = keep a before b, Positive = move b before a, Zero = equal.
Chaining → Commonly combine filter(), map(), and reduce() for clean, readable code.



| Question                    | Short Interview Answer                                                                             |
| --------------------------- | -------------------------------------------------------------------------------------------------- |
| `slice()` vs `splice()`     | `slice()` copies without changing the original; `splice()` changes the original array.             |
| `map()` vs `forEach()`      | `map()` returns a new array; `forEach()` returns `undefined` and is used for side effects.         |
| `filter()` vs `find()`      | `filter()` returns all matching elements as an array; `find()` returns the first matching element. |
| `find()` vs `findIndex()`   | `find()` returns the value; `findIndex()` returns the index.                                       |
| `reduce()`                  | Reduces an array to a single value (sum, object, max, etc.).                                       |
| `sort()`                    | Sorts the array in place; default sorting is lexicographical (string-based).                       |
| Why numeric `sort()` fails? | Numbers are compared as strings unless you provide a comparator like `(a, b) => a - b`.            |
| Mutable methods             | `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse`.                                    |
| Immutable methods           | `map`, `filter`, `reduce`, `slice`, `concat`, `flat`, `flatMap`.                                   |
| Time complexity             | `push()` **O(1)** average, `pop()` **O(1)**, `shift()` **O(n)**, `unshift()` **O(n)**.             |
| Remove duplicates           | `[...]new Set(array)` (or `Array.from(new Set(array))`).                                           |
| Flatten arrays              | `flat()` or `flat(Infinity)` for deeply nested arrays.                                             |
| Merge arrays                | Spread operator (`[...a, ...b]`) or `concat()`.                                                    |
| Shallow vs Deep copy        | Shallow copies share nested references; deep copies duplicate nested objects too.                  |
| `some()` vs `every()`       | `some()` checks if **any** element matches; `every()` checks if **all** elements match.            |
